# 灵感引擎

无聊时按一下，抽 10 条来自不相干领域的火花。点开看，喜欢的收进灵感库,两张撞一下看能不能撞出新点子。

单文件页面，无第三方依赖。数据可以存本地文件，也可以只存在浏览器里。

## 怎么打开

**方式一：双击 `启动.bat`（推荐）**

起一个本地服务（只用 Python 标准库，不用装依赖），自动打开 `http://127.0.0.1:8765/`。数据落在同目录的 `data/` 下，一个 key 一个文件，格式化过的纯文本：

```
data/
  cards.json        卡片（含收藏标记）
  cfg.json          模型配置（含 API key）
  collides.json     碰撞记录
  pack.json         当前这包 + 看到第几张
  bubble.json       泡泡焦点
  view.json         上次停留的视图
  models.json       已验证的模型
  theme_input.json  主题输入框内容
```

可以直接看、直接改、直接 git 管。`data/` 在 `.gitignore` 里，因为 `cfg.json` 存着 API key。

**方式二：双击 `index.html`**

不用起服务，但浏览器不允许网页写本地文件，数据只能进 localStorage。换目录名、换浏览器、清缓存都会丢。

两种方式随时可切：第一次用方式一启动时，如果 `data/` 是空的而浏览器里有旧数据，会自动搬一次过去。

## 用法

1. 双击 `启动.bat`（或者直接用 `index.html`，见上）
2. 点右下角 ⚙ 填 API：任意 OpenAI 兼容接口
   - Base URL：`https://api.deepseek.com/v1`
   - Model：`deepseek-chat`
   - Key：`sk-…`
3. 留空不填 = 用内置的 10 条演示数据，先看手感

主题输入框可以留空（全领域随机），也可以填 `rust`、`产品设计` 之类，
默认 10 条里 6 条跟主题搭得上，4 条完全无关用来制造意外。比例可在设置里调。

### 三种取材方式（点顶栏的 `6/10 · C` 直接循环切换）

| 档 | 含义 | 什么时候用 |
|---|---|---|
| A 直接 | 讲主题本身：工具、API、版本、生态、常见坑 | 想查漏补缺、看看生态里有什么 |
| B 可迁移 | 讲背后的机制与权衡：类型、内存、并发、编译、错误处理、依赖管理 | 想改变自己的默认写法 |
| C 跨领域 | 从生物学/建筑/物流/语言学取材，但机制和主题同构 | 默认档。最容易撞出新点子 |

C 档的关键约束：每条必须点明「X 领域的 A 机制 ↔ 主题里的 B 机制」，
不许写「类似」「可以类比」这种糊过去的表述。所以 C 档的卡片 domain 会显示
生物学、建筑之类，而不是你的主题 —— 这是对的。

## 界面结构

底部三个主视图：

- **抽卡**：流式发牌 + 层叠轮播。模型每写完一张卡就立刻上桌，不用等 10 张全部生成完；中间一张大卡（436 宽），左右各露半张；点左右卡或底部缩略条切换，点中间卡翻面，键盘 ← → 也行。选文字复制时不会误翻面
- **泡泡**：10 个泡泡围成一圈慢慢飘，每 1 分钟自动把下一个放大居中。大卡标题下面有一条倒计时下划线，长度随时间缩短，走完就换下一个；鼠标移上去只冻结、不重置，移开后接着剩下的时间走。点任意泡泡可以立刻切过去。大泡泡右上角 × 或点空白处可以收起，回到全部小泡泡自由飘动的状态；收起后不再自动轮播。默认每 30 分钟自动换一包，底部状态栏会显示还剩几分几秒
- **碰撞**：两个位置可以各自指定一张卡——点 slot 打开选卡面板，按 **当前卡包 / 收藏 / 历史** 三个范围挑（每个 tab 右上角带数量角标），支持搜索；也可以点「随机两张」让它在收藏里随便取。选定后让模型找机制同构、反向借用、值得继续追的问题。输出按 markdown 渲染（小标题、加粗、代码、↔ 高亮、序号徽章），每次碰撞自动存档，最多留 40 条，折叠列表点开看

右上角三个图标：**收藏**（带数量角标）、**历史**（带数量角标）、**设置**。

设置是左侧 tab + 右侧内容的结构，分三页：**模型**（Base URL / Model / API Key / 思考模式 / 测试连接）、**生成**（主题比例 / 取材方式 / 轮播间隔 / 自动换包）、**数据**（备份、恢复、导出 Markdown、清空）。

## 生成后审查

抽卡分两段：先流式生成 10 张（来一张显示一张），全部到齐后再发一次审查请求。

- 审查期间牌堆半透明，顶部提示「审查中 · 逐条核对标题、数字出处和结尾」
- 审查完只替换内容，不重新发牌：卡片正反面、底部缩略条、泡泡卡、本地存储同步更新
- 完成后状态栏追加「· 已审查改写 N 条」
- 审查失败（网络/格式错）静默保留原文，不影响抽卡

审查标准就是 prompt 里那几条：标题不能是废话、数字必须有可核验主体、正文要有反直觉因果、结尾不能是反问句、正文 3-5 句。审查温度 0.3，低随机保证稳定。

设置 →「生成」里可以关掉（`生成后自动审查并改写`），默认开。关掉会快 20–40 秒。

## 朗读

卡片底部有一个喇叭按钮，抽卡卡和泡泡卡都有。

- **抽卡卡**：正面读「标题 + 领域」，翻到背面读正文
- **泡泡卡**：读「标题 + 领域 + 正文」
- 再点一次停止；切到别的视图、关掉自动朗读、或换卡时会自动停

用的是浏览器自带的语音合成（`speechSynthesis`），不联网、不消耗 API 额度。优先挑 `zh-CN` 的语音，没有就用系统默认。

设置 → 生成 → 「切卡时自动朗读标题」打开后，切换卡片会读新卡的标题，翻面会读正文。抽完卡的那一下不读，避免 10 张连着一口气念。

## 卡片渲染接缝

层叠卡在非整数缩放下（Windows 显示缩放 125%）出现过一条贯穿卡片的竖线。

原因：`.deck` 的 `perspective:1800px` 加 `.slide` 的 `will-change:transform` 把卡片推进了浏览器的 3D 合成分块管线，块边界在非整数缩放下会漏 1px，露出下层背景。层叠卡只用 2D 的 `scale` / `rotate`，根本不需要透视，所以直接去掉这两个属性就解决了。

另外在 `.slide.on` 底下垫了一层同色渐变（`.slide.on::before`）兜底：万一哪天又漏，漏出来的是橙色而不是黑线。翻面时这层自动隐藏。

诊断：地址加 `?seam=1`，垫底层换成荧光绿。卡片内部出现绿线就说明有缝，绿线在边缘则是正常的 1px 抗锯齿。

## 卡片上的审查按钮

每张卡底部有「审查」和「改写」两个按钮（正面、背面、泡泡大卡都有）：

- **审查**：把卡片发给模型审查，结果在弹窗里显示（结论 / 问题 / 改写预览），底部出现「应用改写」
- **改写**：一键完成——审查完直接应用改写，弹窗顶上显示「已自动应用改写」，按钮变成「撤销改写」，点一下还原

审查返回的是结构化 JSON（`verdict` / `issues` / `rewrite`），应用时同步更新卡片正面、背面、缩略条、泡泡视图和 localStorage。

审查标准包括：标题是否废话、用词是否准确（动词和比喻要在正文里有对应事实）、数字有无可核验主体、是否有反直觉因果、结尾是否落到类比/边界/代价/反例、有无草稿痕迹（「需核对」「据估计」这类元信息）。

## 主题会显示在视图里

填了主题再抽，抽卡页牌堆左上方会有一个橙色小标签 `主题 · rust`，泡泡页底部的状态栏会以 `主题 rust · 每 1 分钟换一个 …` 开头。

主题是跟着包走的（每张卡都存了 `theme`），所以刷新恢复、换到下一张泡泡、收起大卡都不会丢；没填主题时这个标签整个隐藏。

## 多模型管理

设置 →「模型」分成两半：上面是已配置模型列表，下面是编辑区。

- 列表每项显示 `名称 / 实际模型名 · 主机`，正在用的标「使用中」，没跑通过的标「未验证」
- **点列表项 = 切过去用**，同时把该模型的配置载入下面编辑区
- 「+ 添加模型」清空编辑区，填完点「保存并使用」
- 改动已有模型后保存，验证标记会被清掉（配置变了就得重新证明可用）
- 「×」删除；删的正好是当前使用的，会自动切到列表里第一个
- 顶栏那个模型名下拉开的就是这份列表，也能直接切

每个模型各自记住 `base / model / key / thinking`，切换是整套切换，不会把 DeepSeek 的 key 带到本地服务上。

服务预设除了 DeepSeek / LM Studio / Ollama，还有 **OpenCode Go**：

- Base URL：`https://opencode.ai/zen/v1`（走 `/v1/chat/completions`）
- API Key：在 opencode.ai/console 订阅 Go / Go Plus 后复制
- 模型 ID：控制台里显示的那个，如 `gpt-6-luna`、`glm-5.3`、`kimi-k3`、`claude-haiku-5.5`

注意 Go 和 Console 是同一套端点，区别只在计费方式（月订阅 vs 按量付费）。

验证标记只在真调通一次之后才会打上（抽卡、碰撞、测试连接都算）；从没跑通的模型一样能在列表里看到，只是标着「未验证」。

## 主题历史

输入主题抽过卡之后，主题会被记住（`kg_themes_v1`，最多 30 个，最近用的在前）。
点一下主题输入框就能看到下拉，每项右边是它关联了多少张卡，点一下直接填回输入框。

历史页顶部是主题 tab 条，选项来自上面那份主题历史（外加卡上出现过的主题），每项带条数：

```
[全部 60] [语言学 10] [火生态学 10] [rust 10]   ⋯
```

- 选一个主题就只显示那个主题下的记录，标题右边的副标题同步变成 `rust · 10 条`
- 一行放不下时，多出来的收进右侧 `⋯`，点开是列表，选哪个都能直接切过去
- 鼠标移到 tab 上会出现 `×`，点它把这个主题从列表里移除（只移除标签，卡片还在「全部」里）
- 点卡片上的主题标签也会把 tab 切到那个主题

筛选和搜索是叠加的：先按主题收窄，再在结果里搜关键词。

主题本身也会被记住：

- 主题输入框里填的值存在 `kg_theme_input_v1`，刷新后还在
- 历史页选中的主题存在 `kg_hist_theme_v1`，刷新后回到历史页还是那个筛选
- 最后停留的视图（抽卡/泡泡/历史/收藏）存在 `kg_view_v1`

## 发牌是流式的

抽卡请求带 `stream: true`，边收边解析：

- 从累积文本里用括号配对扫出一个个完整的 `{...}`，凑齐一张就渲染一张
- 切块切断字符串、半截 JSON 都没关系，下一块到了会重新扫
- 第一张到之前，卡片位显示 `生成中…`
- 每张带 0.42s 的淡入 + 去模糊（只动 opacity/filter，不碰 transform，否则和轮播定位打架）

三级兜底，任何一级都能出牌：

1. 流式没拿到东西 → 自动退回一次性请求，拿到后按 90ms 间隔逐张发
2. 还是不行 → 内置演示数据，按 80ms 间隔逐张发，每张带「示例」角标
3. 出错时顶部显示可重试的错误条，但如果退路走通了就不报错

## 刷新不会丢牌

当前这一包（哪 10 张 + 你看到第几张）存在 `kg_pack_v1` 里，刷新页面会自动重建牌堆，
停在原来那张，顶部提示「接着看 · 上次停在第 4 张」。

卡片池本身一直在 `kg_cards_v1`，所以刷新后：已收藏的还在收藏、抽过的还在历史，
新抽一包会覆盖掉「当前这一包」的记录。

`kg_pack_v1` 只存卡片 id 和索引，几十字节，不会撑爆 localStorage。

泡泡视图同样会记住「上次这一包 + 正在看哪个泡泡」，存在 `kg_bubble_v1`；
另外记住你最后停在抽卡还是泡泡（`kg_view_v1`），刷新后直接回到那个视图。

## 模型接入

设置 → **模型** 页，顶部有四档预设：

| 预设 | Base URL | 说明 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | 云端，需要 Key，默认 `deepseek-flash` |
| LM Studio | `http://localhost:1234/v1` | Model 填服务里加载的模型标识，Key 留空 |
| Ollama | `http://localhost:11434/v1` | Key 留空，Model 填 `ollama list` 里的名字 |
| 自定义 | 空 | 填任何 OpenAI 兼容地址，包括 Unsloth Studio |

也可以不动预设，直接手填 Base URL——输入框会按地址自动判断当前属于哪一档。

**API Key 可以为空。** 没填 key 时请求不会带 `Authorization` 头，这正是本地服务要的行为；
填了才会带 `Bearer`。

本地服务的三个坑：

1. **跨域**。浏览器从 `file://` 页面调 `localhost` 会被 CORS 拦。
   - LM Studio：设置里打开 CORS
   - Ollama：设环境变量 `OLLAMA_ORIGINS=*` 后重启
   - Unsloth Studio：看它启动时的 CORS 选项
2. **模型名**。本地服务用的是它自己加载的模型标识，不是 `deepseek-chat` 这种。LM Studio 在
   Local Server 面板能直接复制，Ollama 用 `ollama list`。
3. **速度**。本地小模型吐 10 条长文本很慢，首次加载模型更慢。超时已设 180 秒，
   建议先在 LM Studio / Ollama 里跑一次预热，把模型读进显存。

填完点「测试连接」，它发一个 32 token 的最小请求，两秒内告诉你通不通。

「思考模式」默认关。打开后会按 DeepSeek 的格式发 `thinking:{"type":"enabled"}` 和
`reasoning_effort:"high"`，max_tokens 自动翻倍。本地模型不支持这个字段也不要紧，
400 时会自动去掉重试一次。

已有配置不会被预设覆盖，只有点预设按钮才会改。

## 配色

设计语言照 Hermes Agent 官网（直角、1px 细线、等宽大写标签、超大字重负字距、背景网格），
配色换成朱橙：

- 页面底 `#0A0A0B`，顶部径向暖光
- 品牌色 `#F4511E`，亮橙 `#FF6B35` 用于文字和描边
- 正文 `#F2F2F2`，次要文字 62% 白
- 圆角 2px，边框 1px
- 标题 800 字重、字距 -0.04em

橙底上白字只有 2.6:1，所以所有橙块（hero、卡片正面、泡泡）里的文字一律用 `#121010` 深黑，
对比度 4.8~8.6，随渐变位置变化。深色阅读区保持近黑中性色，不带蓝紫。

蓝色集中在入口和卡牌上，没有整屏铺开：首页 hero 是实心橙块，卡片正面是橙色牌背、
翻面才是深色内容页，小泡泡也是实心橙。

## 注意

- 数据全部存在浏览器 localStorage，不上传。
- **localStorage 是按文件路径隔离的**：改目录名、复制到别的文件夹、换浏览器、清缓存，数据都会没了。
  备份入口在 **设置 → 数据** 页：「备份全部数据」导出 JSON（所有卡片 + 收藏标记 + 碰撞记录 + 设置，不含 API key），
  「恢复备份」合并导入并按 id 去重，不会覆盖现有内容，「清空所有数据」需要连点两次确认。
  换目录的正确顺序是：在新目录打开 index.html → 设置 → 数据 → 恢复备份。
- 从 `file://` 直接调 API 可能被 CORS 拦。若报网络错误，在本目录起个静态服务：
  ```
  python -m http.server 8080
  ```
  然后访问 http://localhost:8080
- 报「无法解析模型返回的 JSON」：现在会自动修复这几种情况——markdown 代码块包裹、JSON 前后夹着「好的，以下是…」、对象包了一层 `{"cards":[…]}`、尾逗号、中文引号、一行一个对象的 JSONL、以及输出被截断（保留已完整的条目并提示「只拿到 N 条」）。仍然失败时错误条会显示原文前 200 字，把它发出来就能定位。
- 模型输出经常被截断（提示「只拿到 N 条」）：说明 max_tokens 不够。抽卡已设 4096，碰撞 3000；如果模型特别啰嗦，换 `deepseek-chat` 这类话少的。
- 碰撞报「API 返回为空」：八成用的是推理模型（DeepSeek R1、o 系列这类），思考过程先烧掉了 token，正文没出来。代码会先尝试用 reasoning_content，仍为空就把原始响应前 160 字打出来。换一个非推理模型最稳。
- 报「返回里没有 choices」：这个接口不是 OpenAI 兼容格式，检查 Base URL 是不是少了 `/v1`。
